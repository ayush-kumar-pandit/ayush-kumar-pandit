I recently spent time at **Jio Platforms Limited** crafting agentic frameworks for system monitoring.

- 🌱 **Currently exploring:** applying ML fundamentals (scikit-learn) to backend telemetry data
- 💬 **Ask me about:** Django/DRF, API design, SQL optimization, or turning messy datasets into a clean story
